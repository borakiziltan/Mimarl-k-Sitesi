# Mimarlık Sitesi 🏡

## Proje Hakkında
Bu proje, HTML ve CSS kullanılarak oluşturulmuş bir mimarlık web sitesi tasarımıdır. Modern ve sade bir ana sayfa hazırlamak amacıyla geliştirilmiştir.

## Projenin Amacı
HTML ile web sayfasının yapısını oluşturmayı ve CSS ile sayfanın tasarımını düzenlemeyi öğrenmek.

## Hedeflerimiz
- HTML ve CSS bilgilerimizi geliştirmek.
- Modern ve kullanıcı dostu bir web sitesi tasarlamak.
- Siteye yeni sayfalar ve özellikler eklemek.
- Projeyi zamanla daha kapsamlı bir mimarlık sitesine dönüştürmek.

## Kullanılan Teknolojiler
- HTML5
- CSS3

## Geliştirme Durumu
Proje geliştirme aşamasındadır. Tasarım ve içerikler zamanla güncellenecektir.
